# Selected indicators from IHME's GBD database, in DDF format

This dataset contains some indicators from IHME GBD database.

## NOTEs

- Files are downloaded from GBD's result tool, which will be csvs compressed in zip files
- usually csv files are large, you can explore it with tools that can filter csvs, such as grep, head etc. You could suggest which tool to use too, the user can install it for you.
- After editing Python scripts, always run `ruff format` to format the code
